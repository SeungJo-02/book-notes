## 🗂️ 폴더 구조

```
book-notes/
├── README.md
└── <책-이름>/
    ├── README.md        # 책 소개 · 목차 · 한줄평
    ├── 01-<장-제목>.md
    ├── 02-<장-제목>.md
    └── ...
```

- 책마다 폴더 하나를 만듭니다. (예: `system-design-1/`)
- 장(chapter)마다 마크다운 파일 하나. 번호를 앞에 붙여 순서를 유지합니다.
- 폴더 안 `README.md`에 그 책의 목차와 링크를 모아둡니다.

## ✍️ 정리 규칙

각 노트는 아래 구조로 작성합니다.

- **한 줄 요약**: 그 장/절을 한 문장으로 (`> 🧩`)
- **핵심 개념**: 비교는 표로, 나열은 불릿으로
- **셀프 체크**: 끝에 복습용 질문 3개 + 답은 `<details>` 토글로 접기
- **원본 노트**: 맨 아래 `📄 원본 노트` 토글에 정리 전 원문(직접 필기)을 그대로 보존

> 정리본과 원본을 함께 담아, 정리가 원뜻을 왜곡했는지 언제든 대조할 수 있게 합니다.
