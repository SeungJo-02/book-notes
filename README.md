> 새 책을 시작하면 위 표에 추가하고, 아래 규칙대로 폴더를 만듭니다.

## 🗂️ 폴더 구조

```
book-notes/
├── README.md
└── <책-이름>/
    ├── README.md        # 책 소개 · 목차 · 한줄평
    ├── 01-<장-제목>.md
    ├── 02-<장-제목>.md
    └── ...
```

- 책마다 폴더 하나를 만듭니다. (예: `system-design-1/`)
- 장(chapter)마다 마크다운 파일 하나. 번호를 앞에 붙여 순서를 유지합니다.
- 폴더 안 `README.md`에 그 책의 목차와 링크를 모아둡니다.

## ✍️ 정리 규칙

- **핵심 요약**: 개념을 내 말로 3~5줄 요약
- **면접 답변**: 실제로 말할 수 있는 문장으로
- **다이어그램**: 흐름이 중요하면 mermaid 사용
- **셀프 체크**: 각 장 끝에 복습용 질문 2~3개
