# LESSON 23. 서브넷과 서브넷 마스크

> 🧩 **한 줄 요약** — 클래스 하나를 통째로 쓰면 IP가 낭비된다. **서브넷팅**은 호스트 ID 일부를 떼어 **네트워크를 잘게 쪼개는** 것이고, **서브넷 마스크**는 그 경계(어디까지가 네트워크 ID인지)를 알려주는 구분자다.

## 1. 서브넷 & 서브넷팅
- **서브넷** = 하나의 네트워크를 분할한 작은 네트워크.
- **서브넷팅** = 큰 네트워크를 작은 네트워크로 나누는 작업.
- 이유: 클래스(A·B·C) 하나를 통째로 한 네트워크로 쓰는 건 **IP 낭비**라 비효율 → 그래서 서브넷이 등장.

## 2. 서브넷팅 원리
- **네트워크 ID는 고정**, **호스트 ID를 쪼갠다.** 즉 호스트 ID를 **서브넷 ID + (남은) 호스트 ID**로 나눔.
- **트레이드오프**: 많이 쪼갤수록 서브넷 수는 늘지만, 서브넷당 쓸 수 있는 **호스트 수는 줄어든다.** (적게 쪼갤수록 호스트 여유↑)

## 3. 서브넷 마스크
- IP에서 **네트워크 ID와 호스트 ID를 구분하는 구분자.** 네트워크 ID 자리는 **1로 꽉**, 호스트 ID 자리는 **0으로 꽉** 채운다.
- **CIDR 표기** `/24` = 앞에서부터 네트워크 ID가 24비트라는 뜻.

| 표기 | 서브넷 마스크 | 의미 |
|---|---|---|
| `192.168.1.1/24` | 255.255.255.0 | 앞 24비트=네트워크 ID, 뒤 8비트=호스트 |

## 🔁 셀프 체크
1. 서브넷팅을 왜 하나?
2. 서브넷팅은 IP의 어느 부분을 어떻게 나누나?
3. `/24`는 무슨 뜻이고 서브넷 마스크로는 어떻게 되나?

<details>
<summary>답</summary>

1. 클래스를 통째로 쓰면 IP가 낭비되므로, 네트워크를 알맞게 쪼개 효율적으로 쓰려고.
2. 네트워크 ID는 고정하고 **호스트 ID를 서브넷 ID + 호스트 ID로** 나눈다. 많이 쪼갤수록 서브넷당 호스트 수는 줄어든다.
3. 네트워크 ID가 앞 24비트라는 뜻. 서브넷 마스크는 255.255.255.0(1을 24개 채운 뒤 0).

- 서브넷 : 하나의 네트워크가 분할된 네트워크 / 서브넷팅 : 작은 네트워크로 나누는 작업. 클래스를 하나의 네트워크로 쓰는 건 비효율 → 서브넷

- 서브넷 마스크 : 네트워크ID와 호스트ID 구분자. 192.168.1.1/24(/24는 네트워크ID 비트수) → 255.255.255.0
