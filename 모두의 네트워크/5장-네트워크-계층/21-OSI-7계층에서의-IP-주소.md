# LESSON 21. OSI 7 계층에서의 IP 주소

> 🧩 **한 줄 요약** — 네트워크 계층에서 캡슐화하면 **IP 헤더**가 붙는데, 송·수신 IP뿐 아니라 **TTL·상위 프로토콜·헤더 검사합** 등 여러 정보가 함께 들어간다. 남의 IP는 **라우터**를 통해 찾아간다.

## 1. IP 헤더에 담기는 정보
캡슐화 시 네트워크 계층에서 **송·수신자 IP**만 붙는 게 아니라 더 많은 제어 정보가 들어간다:

| 필드 | 역할 |
|---|---|
| **TTL** (Time To Live) | 패킷 수명 — 라우터를 거칠 때마다 1씩 감소, 0이면 폐기(무한 루프 방지) |
| **상위 계층 프로토콜** | 이 패킷이 TCP인지 UDP인지 표시 |
| **헤더 검사합** | 헤더 오류 검출 |
| **패킷 전체 길이 / 분할 오프셋** | 패킷 크기, 분할(fragmentation) 시 조각 위치 |

## 2. 남의 IP는 어떻게 아나
- 내 IP는 알지만 목적지 IP로 가는 길은 모른다 → **라우터**가 라우팅으로 경로를 찾아준다(→ LESSON 24).

3. 목적지까지 경로는 무엇이 찾아주나?
