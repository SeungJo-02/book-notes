# LESSON 20. IP 주소의 구조와 클래스

> 🧩 **한 줄 요약** — IP 주소(32비트)는 **네트워크 ID + 호스트 ID**로 나뉜다. 그 경계를 어디에 두느냐가 **클래스(A·B·C)**이고, 전 세계 IP는 **IANA → KISA → ISP** 순으로 분배된다.

## 1. IP 구조 — 네트워크 ID + 호스트 ID

| 부분 | 의미 | 예 (192.168.2.124) |
|---|---|---|
| **네트워크 ID** | 어느 네트워크인지 | 192.168.2 |
| **호스트 ID** | 그 안의 개별 컴퓨터 | .124 |

- 호스트 ID = 라우터에 연결된 개별 컴퓨터들을 구분·관리하는 번호.

## 2. IP 클래스 (A~E)

D·E는 일반용이 아니다(D=멀티캐스트, E=연구용). 실사용은 A·B·C:

| 클래스 | 네트워크 ID | 호스트 ID | 앞 비트 |
|---|---|---|---|
| **A** | 첫 8비트 | 나머지 24비트(호스트 최다) | 0… |
| **B** | 첫 16비트 | 나머지 16비트 | 10… |
| **C** | 첫 24비트 | 나머지 8비트 | 110… |

> 네트워크 ID가 짧을수록(A) 호스트 ID가 길어 **한 네트워크가 담을 수 있는 컴퓨터가 많다.**

## 3. IP는 누가 나눠주나
- **IANA** — 전 세계 IP 총괄 관리.
- **KISA** — IANA에서 한국 IP 대역을 받아옴.
- **ISP** — KISA가 넘겨준 대역을 사용자에게 배분. → 우리가 사용.
