# LESSON 04. 네트워크 구성 장치

> 🧩 **한 줄 요약** — 네트워크 장치는 각자 **OSI 계층**이 다르다: 허브(1계층) · 브리지/스위치(2계층) · 라우터(3계층). "몇 계층 장치냐"가 곧 그 장치가 하는 일을 결정한다.

## 1. 주요 구성 장치

| 장치 | 역할 | 계층 |
|---|---|---|
| **허브** | 여러 장치를 연결(신호를 모두에게 복제) | 1 (물리) |
| **브리지** | LAN 내부 장치끼리 데이터를 주고받게 중계 | 2 (데이터링크) |
| **스위치** | 대역폭 확대(MAC 기반으로 원하는 포트에만 전달) | 2 (데이터링크) |
| **라우터** | 다른 네트워크 위치로 경로 안내 | 3 (네트워크) |

## 2. 대역폭 (bandwidth)
- **대역폭(bps)** = 초당 처리 가능한 데이터 양. `대역폭 = (용량 × 8) ÷ 처리시간`
- 단위 관계:
  - **비트(bit)** = 0과 1 하나 / **바이트(Byte)** = 8비트
  - KB → MB → GB → TB : 각 단계 **2^10(=1024)배**

## 🔁 셀프 체크
1. 허브·스위치·라우터는 각각 몇 계층 장치인가?
2. 대역폭의 정의와 계산식은?
3. 1바이트는 몇 비트이고, KB→MB는 몇 배인가?

<details>
<summary>답</summary>

1. 허브=1계층(물리), 스위치·브리지=2계층(데이터링크), 라우터=3계층(네트워크).
2. 초당 처리 가능한 데이터 양(bps). `(용량×8)÷처리시간`.
3. 1바이트=8비트, KB→MB는 2^10(1024)배.
