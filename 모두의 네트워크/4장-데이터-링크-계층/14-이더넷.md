# LESSON 14. 이더넷

> 🧩 **한 줄 요약** — **이더넷**은 유선 LAN의 표준 방식. 하나의 통신 매체를 여럿이 나눠 쓰다 보니 충돌이 나는데, 이를 **CSMA/CD**(보내기 전 확인 → 충돌 시 재전송)로 관리한다. 요즘은 스위치가 대신해 거의 안 쓴다.

## 1. 이더넷이란
- 여러 컴퓨터·허브·스위치를 **하나의 통신 구조로 묶은** 유선 LAN 표준.
- 매체를 공유하므로 2대 이상이 동시에 프레임을 보내면 **충돌**이 발생 → 관리가 필요.

## 2. CSMA/CD

**Carrier Sense Multiple Access / Collision Detection** — "보내기 전에 회선을 엿듣고(Carrier Sense), 충돌을 감지(Collision Detection)하면 대응"하는 프로토콜.

- 기본 흐름: **송신 전 케이블 사용 여부 확인** → 비어 있으면 전송 → 전송 중에도 충돌 계속 감시 → 충돌 시 잠시 후 재전송.

### 2-1. 회선이 사용 중일 때의 대기 전략

| 방식 | 동작 | 특징 |
|---|---|---|
| **1-persistent** | 비면 즉시 전송 | 동시 전송 겹칠 확률↑ |
| **nonpersistent** | 비면 바로, 사용 중이면 잠깐 뒤 재확인 | 충돌↓, 지연↑ |
| **p-persistent** | 비면 확률 p로 전송/아니면 대기 | 둘의 절충 |

> 💡 참고 — **CSMA/CD = 유선** 이더넷용. 무선(Wi-Fi)은 충돌 감지가 어려워 미리 피하는 **CSMA/CA**(Collision Avoidance)를 쓴다. 요즘 유선망은 스위치가 포트를 분리해 충돌 자체를 없애므로 CSMA/CD는 거의 안 쓴다.

3. 요즘 CSMA/CD를 잘 안 쓰는 이유는?
