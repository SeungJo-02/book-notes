# LESSON 05. 네트워크의 규칙, 프로토콜

> 🧩 **한 줄 요약** — **프로토콜**은 서로 다른 장치가 대화할 수 있도록 정한 "공통 규칙". 데이터의 형식·순서·의미를 미리 약속해 둔 것.

- **프로토콜** = 메시지를 주고받는 **양식과 규칙의 체계**. 서로 제조사·OS가 달라도 같은 규칙을 따르면 통신이 된다.
- 규칙이 정하는 것: **무엇을**(형식) · **어떤 순서로**(절차) · **어떤 의미로**(해석) 주고받을지.
- 예: HTTP(웹), TCP/IP(인터넷 전송), FTP(파일 전송) — 각 목적마다 프로토콜이 있다.

## 🔁 셀프 체크
1. 프로토콜이란 무엇인가?
2. 프로토콜이 없으면 어떤 문제가 생기나?
3. 프로토콜이 정하는 3가지 요소는?

<details>
<summary>답</summary>

1. 장치들이 메시지를 주고받기 위해 정한 공통 양식·규칙의 체계.
2. 제조사·OS마다 방식이 달라 서로 데이터를 해석하지 못해 통신이 안 된다.
3. 데이터의 형식(무엇을) · 절차/순서(어떻게) · 의미(어떤 뜻으로).
