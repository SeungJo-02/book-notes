# LESSON 06. OSI 7 계층과 TCP/IP 4 계층

> 🧩 **한 줄 요약** — **OSI 7계층**은 통신 과정을 7단계로 표준화한 모델, **TCP/IP 4계층**은 이를 실무용으로 4단계로 묶은 것. 보낼 땐 위(7)→아래(1), 받을 땐 아래(1)→위(7)로 흐른다.

## 1. OSI 7계층 — ISO의 통신 표준

제조사마다 제각각이던 통신 방식을 하나로 통일하기 위해 ISO가 제정한 표준 모델.

| 계층 | 이름 | 한 줄 역할 |
|---|---|---|
| 7 | 응용 | 사용자와 만나는 서비스(HTTP·메일) |
| 6 | 표현 | 데이터 형식 변환·암호화·압축 |
| 5 | 세션 | 연결(대화) 시작·유지·종료 |
| 4 | 전송 | 양 끝점 간 신뢰성 전달(TCP/UDP) |
| 3 | 네트워크 | 목적지까지 경로 지정(IP·라우팅) |
| 2 | 데이터링크 | 같은 망 안 장치 간 전달(MAC) |
| 1 | 물리 | 비트를 전기 신호로 변환·전송 |

- **송신자 → 수신자 : 7 → 1** (내려가며 헤더 추가 = 캡슐화)
- **수신자 → 송신자 : 1 → 7** (올라가며 헤더 제거 = 역캡슐화)

## 2. TCP/IP 4계층 — 실무용 축약 모델

OSI가 너무 세분화돼 있어 실제 인터넷은 4계층으로 묶어 쓴다.

| TCP/IP 4계층 | 대응 OSI |
|---|---|
| 응용 | 5~7 (응용·표현·세션) |
| 전송 | 4 (전송) |
| 인터넷 | 3 (네트워크) |
| 네트워크 인터페이스 | 1~2 (데이터링크·물리) |

## 🔁 셀프 체크
1. OSI 7계층을 1→7 순서로 말해보라.
2. 데이터를 보낼 때 계층은 어느 방향으로 흐르는가?
3. TCP/IP 4계층의 "응용"은 OSI의 어느 계층들을 묶은 것인가?

<details>
<summary>답</summary>

1. 물리 → 데이터링크 → 네트워크 → 전송 → 세션 → 표현 → 응용.
2. 송신은 7(응용)→1(물리)로 내려가며 헤더를 붙이고(캡슐화), 수신은 1→7로 올라가며 제거한다(역캡슐화).
3. OSI의 5·6·7(세션·표현·응용)을 하나로 묶은 것.
