# LESSON 07. OSI 7 계층에서의 데이터 표현

> 🧩 **한 줄 요약** — 같은 데이터라도 계층마다 부르는 이름(**PDU**)이 다르다: 전송=세그먼트, 네트워크=패킷, 데이터링크=프레임, 물리=비트. 각 계층은 자기 헤더에 필요한 주소(포트·IP·MAC)를 담는다.

## 1. 계층별 데이터 단위 (PDU)

각 계층에서 다루는 데이터 덩어리를 **PDU**(Protocol Data Unit)라 하고 이름이 다르다.

| 계층 | 데이터 이름 | 담기는 주소 |
|---|---|---|
| 응용·표현·세션 | 데이터 / 메시지 | — |
| 전송 | **세그먼트** | 포트 번호 |
| 네트워크 | **패킷** | IP 주소 |
| 데이터링크 | **프레임** | MAC 주소 (+ 트레일러) |
| 물리 | **비트** | — |

> 안쪽(데이터)부터 감싸는 구조: `[MAC | IP | 포트 | 데이터 | 트레일러]` — 바깥일수록 아래 계층.

## 2. 주소·필드 정리

| 용어 | 무엇 | 어디서 |
|---|---|---|
| **포트 번호** | 어떤 애플리케이션(메일·웹 등)인지 구분 | 전송 계층 |
| **IP 주소** | 장치의 논리적 고유 번호(인터넷 가입 시 받음) | 네트워크 계층 |
| **MAC 주소** | 하드웨어(랜카드)에 새겨진 물리 고유 번호 | 데이터링크 계층 |
| **트레일러** | 전달된 데이터에 오류가 없는지 검출용 | 데이터링크 계층(프레임 끝) |

## 🔁 셀프 체크

2. 포트 번호·IP·MAC은 각각 무엇을 구분하는가?
3. 트레일러는 왜 붙는가?

<summary>📄 원본 노트 (정리 전 원문)</summary>

- OSI 계층마다 부르는 용어가 다르다 : 응용/표현/세션(데이터,메시지), 전송(세그먼트), 네트워크(패킷), 데이터링크(프레임), 물리(비트)
- 프레임(송수신자 MAC+트레일러) > 패킷(송수신자 IP) > 세그먼트(포트번호) > 데이터,메시지
- 포트번호 : 애플리케이션 구분 / IP : 장치 고유번호(네트워크 계층) / MAC : H/W 고유번호 / 트레일러 : 오류 검출용

</details>
