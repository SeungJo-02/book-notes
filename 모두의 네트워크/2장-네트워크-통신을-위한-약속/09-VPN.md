# LESSON 09. VPN

> 🧩 **한 줄 요약** — **VPN**은 공용 인터넷 위에 **암호화된 사설 통로(터널)**를 만들어 데이터를 안전하게 주고받는 기술. 계층에 따라 IPSec(3계층)·SSL(4~7계층)로 나뉜다.

## 1. VPN이란
- **VPN**(Virtual Private Network) = 공용 인터넷을 통해 데이터를 **안전하게** 전송하기 위한 기술.
- 핵심은 **터널링** — 송신자·수신자 사이에 암호화된 전용 통로를 만들어, 중간에서 누구도 내용을 볼 수 없게 한다.

## 2. 동작 순서
1. **VPN 클라이언트 SW 설치**
2. **서버 연결 및 인증** — 사용자 이름·암호로 VPN 서버에 접속
3. **데이터 암호화** — 연결되면 모든 데이터가 암호화되어 전송(제3자가 못 봄)
4. **터널링** — 서버와 클라이언트를 잇는 암호화 통로로 통신
5. 통신이 끝나면 **터널·연결 해제**

## 3. 종류

| 종류 | 동작 계층 | 접속 방식 |
|---|---|---|
| **IPSec** | 3계층(네트워크)에서 IP 암호화 | 전용 SW 설치 후 접속 |
| **SSL** | 4~7계층 데이터 암호화 | 웹 브라우저에서 접속 |

- VPN : 인터넷을 통해 데이터를 안전하게 전송하기 위한 기술
  - 동작 : 클라이언트 SW 설치 → 서버 연결·인증(이름·암호) → 데이터 암호화 → 터널링(서버·클라이언트 잇는 통로) → 통신 끝나면 해제
  - 종류 : IPSec(3계층 IP 암호화+SW 설치) / SSL(4~7계층 암호화+브라우저 접속)
