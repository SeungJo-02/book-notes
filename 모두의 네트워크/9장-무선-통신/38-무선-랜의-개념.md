# LESSON 38. 무선 랜의 개념

> 📝 **Notion 원본**: https://app.notion.com/p/3c4d7d6851ff81518300dd1673052e26

> 🧩 **한 줄 요약** — 무선 랜은 케이블 대신 **전파** 로 통신한다. 유선과의 결정적 차이는 **모두가 같은 공간(매체)을 공유한다** 는 점이고, 이후의 모든 규칙(충돌 회피·채널·보안)이 여기서 파생된다.

---

## 1. 무선 랜이란

- 무선 랜(WLAN) : **케이블 없이** 통신하는 네트워크
- **액세스 포인트(AP, 무선 공유기)** : 유선 랜과 무선 랜을 이어주는 장치
  - 무선으로 받은 데이터를 유선 쪽으로 넘겨줘야 인터넷에 나갈 수 있음
  - **클라이언트** : AP에 연결된 장치 (노트북·스마트폰)
- 흐름 : 클라이언트 → (전파) → AP → (유선) → 라우터 → 인터넷

## 2. 전파의 성질 — 주파수

- 데이터는 **전자기파(전파)** 에 실려 전달됨
- **저주파** : 멀리 전달, 장애물을 잘 통과 / 대신 **속도가 느림**
- **고주파** : 짧게 전달, 장애물에 약함 / 대신 **속도가 빠름**
- → 무선은 **거리와 장애물의 영향을 크게 받는다**

> 📌 **실제 대역이 바로 이 이야기다.** 우리가 공유기에서 보는 **2.4GHz와 5GHz** 가 저주파·고주파의 구체적인 사례다.
> - **2.4GHz** — 멀리 가고 벽을 잘 뚫음. 대신 느리고, 전자레인지·블루투스와 대역이 겹쳐 **간섭이 심함**
> - **5GHz** — 빠르고 간섭이 적음. 대신 **거리가 짧고 벽에 약함**
> - 그래서 공유기가 두 대역을 동시에 제공하고, 기기가 상황에 따라 골라 붙는다.

## 3. 유선과 다른 점 (이 장 전체의 전제)

| 기준 | 유선 랜 | 무선 랜 |
|---|---|---|
| 매체 | 케이블 (**독점**) | 공기 (**모두가 공유**) |
| 통신 방식 | 전이중 (동시 송수신) | **반이중** (한 번에 한쪽만) |
| 충돌 처리 | 충돌 **감지** (CSMA/CD) | 충돌 **회피** (CSMA/CA) → LESSON 41 |
| 도달 범위 | 케이블이 닿는 곳 | 전파가 닿는 곳 — **벽을 넘어감** |
| 보안 | 물리적으로 접근해야 함 | **밖에서도 신호를 잡을 수 있음** → 암호화 필수 |

- 무선이 **충돌을 감지하지 못하는 이유** : 자기가 송신하는 신호가 너무 커서 동시에 오는 남의 신호를 들을 수 없음 → 그래서 **부딪히고 나서 알아채는 대신, 부딪히지 않게 미리 피한다**

## 4. 정리

| 개념 | 한 줄 정의 |
|---|---|
| 무선 랜 | 전파로 통신하는 네트워크 |
| 액세스 포인트 | 무선과 유선을 이어주는 장치 |
| 저주파 / 고주파 | 멀리·느리게 / 짧게·빠르게 (2.4GHz / 5GHz) |
| 매체 공유 | 모두가 같은 공기를 씀 → 반이중 + 충돌 회피 필요 |

## 🔁 셀프 체크

1. 2.4GHz와 5GHz 중 벽 너머 방까지 잘 가는 쪽은? 그 이유는?
2. 무선 랜이 유선과 달리 충돌을 **감지** 하지 못하는 이유는?
3. 무선에서 암호화가 필수인 이유는?

<details>
<summary>답</summary>

1. **2.4GHz.** 주파수가 낮을수록 멀리 가고 장애물을 잘 통과하기 때문. 대신 속도는 5GHz보다 느리다.
2. 자기가 **송신 중인 신호가 너무 커서** 동시에 도착하는 남의 신호를 들을 수 없기 때문. 그래서 감지 대신 **회피(CSMA/CA)** 를 쓴다.
3. 전파는 **벽을 넘어 건물 밖까지 도달** 하므로, 물리적으로 접근하지 않아도 신호를 잡을 수 있다. 유선처럼 "선을 꽂아야 한다"는 방어막이 없다.
