# LESSON 33. DHCP 서버

> 📝 **Notion 원본**: https://app.notion.com/p/3c4d7d6851ff8144a45fc4e9b8578e47

> 🧩 **한 줄 요약** — DHCP는 IP 주소를 **손으로 하나씩 적어 넣는 일** 을 없애준다. 핵심 절차는 **DORA 4단계** 이고, 받은 IP는 소유가 아니라 **기한이 있는 임대** 다.

---

## 1. 무슨 문제를 푸는가

- IP는 네트워크 안에서 **겹치면 안 된다.** 수동으로 관리하면 중복 배정과 오타가 반드시 생긴다.
- DHCP 서버가 주소 풀을 갖고 **할당과 회수를 자동으로** 처리한다.
- 노트북을 들고 카페·회사·집을 옮겨 다녀도 설정을 만질 필요가 없는 이유가 이것.

---

## 2. DORA — 네 단계

| 단계 | 방향 | 내용 |
|---|---|---|
| **D**iscover | 클라 → 전체 | "DHCP 서버 계신가요?" (브로드캐스트) |
| **O**ffer | 서버 → 클라 | "**이 IP 어때요?**" — 후보 주소를 **제안** |
| **R**equest | 클라 → 전체 | "그 IP로 할게요" (정식 요청) |
| **A**ck | 서버 → 클라 | "확정. 임대 기간은 N시간" ← 이때부터 사용 |

> ✏️ **정정** — 원본에는 2단계를 "DHCP 서버는 사용자에게 **IP 할당 받을 건지 여부를 묻는다**"라고 적었는데, 서버는 의사를 묻는 게 아니다. **구체적인 IP 후보를 하나 찍어서 제안(Offer)** 한다. 클라이언트는 이미 받을 마음이 있어서 Discover를 보낸 것이고, 남은 선택은 "받을지 말지"가 아니라 **"제안된 그 주소를 쓸지"** 다.

- **Discover와 Request가 브로드캐스트인 이유** — 아직 내 IP가 없어서 상대를 특정해 보낼 수 없다. Request까지 브로드캐스트로 보내는 건, 서버가 여러 대일 때 **선택받지 못한 서버들이 자기가 잡아둔 주소를 풀 수 있게** 알려주기 위해서다.
- 포트는 **서버 67 / 클라이언트 68**, UDP를 쓴다.

---

## 3. 임대(Lease)와 갱신

- 받은 IP는 **영구 소유가 아니라 기한부 임대** 다. 기기가 사라져도 주소를 회수할 수 있어야 하기 때문.
- 임대 기간의 **절반쯤 지나면** 클라이언트가 먼저 같은 서버에 갱신을 요청한다. 실패하면 **약 87.5% 지점** 에서 아무 서버에나 다시 요청한다.
- 갱신에 계속 실패해 기한이 끝나면 주소를 반납하고 **DORA를 처음부터** 다시 밟는다.

<details>
<summary>⚠️ 실무에서 물리는 지점</summary>

- **서버·프린터·공유기는 DHCP로 두면 안 된다.** 주소가 바뀌면 접속하던 쪽이 전부 길을 잃는다. 고정 IP를 쓰거나, MAC 주소에 늘 같은 IP를 주는 **DHCP 예약** 을 건다.
- DHCP는 **브로드캐스트** 기반이라 라우터를 넘지 못한다. 다른 네트워크의 서버를 쓰려면 라우터에 **DHCP 릴레이** 를 설정해 대신 전달하게 해야 한다.
- 네트워크에 **가짜 DHCP 서버** 가 붙으면 엉뚱한 게이트웨이를 나눠줘 통신을 가로챌 수 있다. 스위치의 **DHCP 스누핑** 으로 막는다.

</details>

---

## 4. 정리

| 개념 | 한 줄 정의 |
|---|---|
| DHCP | IP 할당·회수를 자동화하는 프로토콜 |
| DORA | Discover → Offer → Request → Ack |
| Offer | 서버가 **후보 IP를 제안** 하는 단계 |
| Lease | 기한이 정해진 IP 임대 (절반 지나면 갱신) |

---

## 🔁 셀프 체크

1. Discover는 왜 브로드캐스트로 보내는가?
2. Offer 단계에서 서버가 보내는 것은 "받을래?"인가, 아니면 다른 것인가?
3. 사무실 프린터에 DHCP를 쓰면 무엇이 문제인가?

<details>
<summary>답</summary>

1. 아직 **자기 IP도, 서버 주소도 모르기 때문** 에 특정 상대를 지정해 보낼 수 없다.
2. **구체적인 IP 후보를 제안(Offer)** 하는 것이다. 의사를 묻는 단계가 아니다 — 클라이언트는 이미 받으려고 Discover를 보냈다.
3. 임대가 갱신되며 **IP가 바뀔 수 있어**, 그 주소로 인쇄하던 PC들이 프린터를 찾지 못한다. 고정 IP나 DHCP 예약을 써야 한다.

</details>
