# LESSON 29. 전송 계층에서 사용하는 로드 밸런서

> 📝 **Notion 원본**: https://app.notion.com/p/3c4d7d6851ff8111aa95d045644148ca

> 🧩 **한 줄 요약** — 로드 밸런서는 여러 서버에 **부하를 고르게 분산**한다. 알고리즘은 라운드로빈·가중 라운드로빈·랜덤·해시가 있고, **포트 번호** 기준으로도 나눌 수 있다.

---

## 1. 로드 밸런서란

- 하나의 서비스에 여러 서버를 쓸 때, **한 곳으로 부하가 몰리지 않게** 요청을 나눠주는 역할.

## 2. 분산 알고리즘

| 방식 | 설명 |
|---|---|
| **라운드로빈** | 서버를 순서대로 돌아가며 배정 |
| **가중 라운드로빈** | 라운드로빈 + 일부 서버에 트래픽을 더 몰아줌 |
| **랜덤** | 무작위로 배정 |
| **해시** | 특정 클라이언트는 항상 같은 서버가 처리 |

## 3. 포트 기반 분산

- 포트 번호로도 부하를 나눌 수 있다. 예 : `8001` → `172.16.2.201`, `8002` → `172.16.2.202`

3. 로드 밸런서가 필요한 이유는?
