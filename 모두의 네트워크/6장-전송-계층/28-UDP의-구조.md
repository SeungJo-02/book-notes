# LESSON 28. UDP의 구조

> 📝 **Notion 원본**: https://app.notion.com/p/3c4d7d6851ff81f3a38efd2ad7d012c9

> 🧩 **한 줄 요약** — UDP는 확인 절차 없이 **일단 보내는** 비연결형. 신뢰성은 낮지만 **속도가 빨라** 실시간 방송에 적합하다. 헤더는 포트·길이·검사합뿐으로 단순하다.

---

## 1. 특징

- **확인 없이 전송** → 신뢰성↓, 대신 **속도↑**
- 실시간 방송 등에 사용. 네트워크 계층의 **브로드캐스트**가 UDP 방식.

## 2. 헤더 (단순)

| 필드 | 역할 |
|---|---|
| 송/수신 포트 번호 | 데이터를 주고받는 앱의 포트 |
| 헤더 길이 | UDP 헤더 + 데이터 길이 |
| 검사합 | 데이터 무결성 검사 |

---

## 🔁 셀프 체크

1. UDP가 TCP보다 빠른 이유는?
2. UDP는 어떤 통신에 적합한가?
3. UDP 헤더의 검사합은 무슨 역할을 하나?

<details>
<summary>답</summary>

1. ACK·핸드셰이크 같은 확인 절차 없이 일단 보내기 때문에 오버헤드가 적어 빠르다.
2. 신뢰성보다 속도가 중요한 실시간 방송·스트리밍 등. 브로드캐스트도 UDP 방식.
3. 전달된 데이터가 훼손되지 않았는지 무결성을 검사한다.

</details>
