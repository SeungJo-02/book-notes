# LESSON 12. 리피터와 허브가 통신하는 방법

> 📝 **Notion 원본**: https://app.notion.com/p/3c4d7d6851ff81a3a518d56ca1454638

> 🧩 **한 줄 요약** — **리피터**는 약해진 신호를 증폭, **허브**는 신호를 복원해 여러 대에 뿌린다. 둘 다 1계층 장치이며, 허브는 받은 데이터를 **연결된 모두에게 그대로 복제(브로드캐스트)**한다.

## 1. 리피터
- 거리가 멀어지면 전기 신호가 **감쇠**되는데, 이를 **증폭해 그대로 전달**하는 장치.
- 포트가 1개(1:1). 요즘은 허브·스위치가 그 기능을 겸해 **거의 쓰지 않는다.**

## 2. 허브
- 일그러진 신호를 **복원·보정**하고, 하나의 입력을 **여러 장치로 복제**한다. 포트가 여러 개라 여러 대를 연결.
- 각 컴퓨터가 허브로 데이터를 보낼 수 있지만, **허브는 특정 대상을 지정하지 못하고 연결된 모두에게 뿌린다**(더미 허브 = 브로드캐스트).

> ⚠️ **허브의 한계** — 모두에게 뿌리므로, 두 대가 동시에 보내면 신호가 겹쳐 **충돌**이 난다. 허브에 연결된 전체가 하나의 **충돌 도메인**이 된다. → 이 문제를 원하는 포트로만 보내 해결하는 게 *스위치*(LESSON 16).

## 🔁 셀프 체크
1. 리피터와 허브의 공통점·차이점은?
2. 더미 허브가 데이터를 보내는 방식은?
3. 허브를 많이 쓰면 생기는 문제는?

<summary>답</summary>

1. 둘 다 신호를 되살려 전달(1계층). 리피터는 포트 1개로 증폭만, 허브는 여러 포트로 복원+복제.
2. 특정 대상을 못 정하고 **연결된 모든 장치에 똑같이 복제**(브로드캐스트)한다.
3. 모두에게 뿌리므로 동시 전송 시 충돌이 잦아진다(충돌 도메인이 커짐).

- 리피터 : 전기 신호를 증폭. 거리 멀수록 감쇠되는데 증폭해 전달. 요즘은 허브가 다 해서 안 씀
