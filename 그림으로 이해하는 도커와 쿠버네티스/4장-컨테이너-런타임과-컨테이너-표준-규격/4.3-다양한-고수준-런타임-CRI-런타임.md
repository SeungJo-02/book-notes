# 4.3 다양한 고수준 런타임 (CRI 런타임)

> 📝 **Notion 원본**: https://app.notion.com/p/3c5d7d6851ff8106a6f3c8973c94f822

## 4.3.1 containerd

> 🧩 **한 줄 요약** — **containerd**는 CNCF가 개발한 성숙한 **CRI 런타임 구현체**. 플러그형 설계로 확장 가능하며, 자체 API·클라이언트 라이브러리를 제공한다.

- **CNCF** 개발 → 성숙도가 높다. **CRI의 구현체**.
- **플러그형 설계** : 용도에 따라 플러그인을 구현해 확장 가능.
- **containerd API + 클라이언트 라이브러리** 제공.

## 4.3.2 CRI-O

> 🧩 **한 줄 요약** — **CRI-O**는 CNCF의 성숙한 CRI 런타임. 쿠버 CRI에 **필요한 기능만** 담아 가볍고, 이미지 관련 컴포넌트가 독립 라이브러리로 개발된다. 파드맨처럼 **conmon 프로세스**로 컨테이너 입출력·로그를 관리한다.

- **CNCF** 소속, 성숙도 높음.
- 다양한 도구와의 **통합**이 가능. 이미지 관련 주요 컴포넌트가 **각자 독립 라이브러리 프로젝트**로 개발됨.
- **CRI를 통해 안 쓰는 기능은 제외** → 가볍다.
- **conmon 프로세스**로 컨테이너별 입출력 관리·로그 수집 (파드맨과 유사).
