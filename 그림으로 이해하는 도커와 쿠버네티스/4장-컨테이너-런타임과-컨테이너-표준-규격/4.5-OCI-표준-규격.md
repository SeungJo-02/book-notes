# 4.5 OCI 표준 규격

## 4.5.1 OCI Runtime Specification

> 🧩 **한 줄 요약** — **OCI Runtime Specification**은 저수준 런타임 규격. **파일시스템 번들**(루트 파일시스템 + 실행 설정 파일)의 형식과 컨테이너 **생명주기 동작**(create/start/kill/delete/state)을 정해, 런타임을 갈아끼워도 동일하게 실행되게 한다.

### 1. 파일시스템 번들
- 컨테이너 작성의 기반. 고수준 런타임이 이미지를 가져와 저수준 런타임에 넘길 때의 **저장 방법**을 정한 규격.

| 구성 | 역할 |
|---|---|
| **루트 파일시스템** | 컨테이너 전용 '가상 C드라이브' |
| **실행 환경 설정 파일** | 어떻게 띄울지 적은 '실행 설명서' — CPU/메모리 제한(cgroups), 격리 규칙(namespaces), 환경 변수, 시작 명령 등 |

### 2. 컨테이너 생명주기 동작
- **create** : 번들을 OCI 호환 런타임에 지정해 컨테이너 작성
- **start** : 컨테이너 실행 시작
- **kill** : 컨테이너 내부 앱 종료
- **delete** : 컨테이너 삭제
- **state** : 컨테이너 상태 확인

## 4.5.2 OCI Image Specification

> 🧩 **한 줄 요약** — **OCI Image Specification**은 이미지의 구성 요소·배치·미디어 종류를 정한 규격. 핵심은 **매니페스트**(설계도 JSON)·**레이어**(루트파일시스템, tar+gzip)·**구성 파일**(실행 정보 JSON)·**인덱스**(멀티아키텍처용, 선택). 참조 구조는 인덱스 → 매니페스트 → (구성 파일 + 레이어).

| 요소 | 역할 |
|---|---|
| **매니페스트** | 이미지 설계도 JSON. **디스크립터**로 다른 컴포넌트(미디어 종류·크기·다이제스트)를 가리킨다 |
| **레이어** | 루트 파일시스템의 구조. 보통 **tar + gzip**으로 압축 |
| **구성 파일** | 컨테이너 실행 시 필요한 정보가 담긴 JSON |
| **인덱스** | (선택) **멀티 아키텍처** 대응 이미지를 만들 때 쓰는 JSON |

- 참조 구조 : **인덱스 → 매니페스트 → 구성 파일 + 레이어**

## 4.5.3 OCI Distribution Specification

> 🧩 **한 줄 요약** — **OCI Distribution Specification**은 **레지스트리 API**를 정의하는 규격. 도커 레지스트리 HTTP API를 기반으로 만들어져 공통점이 많다.

- 이미지를 주고받는 **레지스트리 API**를 정의.
- **도커 레지스트리 HTTP API**를 기반으로 규격이 만들어짐 → 그래서 공통 부분이 많다.

> 💡 OCI 3대 규격 정리 — **Runtime**(컨테이너 실행 방법) · **Image**(이미지 구성) · **Distribution**(레지스트리로 배포).

      - 루트파일 시스템과 실행황경 설정 파일로 구성

          - 컨테이너가 독립적으로 사용할 전용 '가상 C드라이브'
        - 실행환경 설정 파일

    - 파일 시스템 번들을 OCI 호환 런타임에 지정해서 컨테이너 작성(create)
    - 컨테이너 실행 시작(start)
    - 컨테이너 내부 APP 종료(kill)
    - 컨테이너 삭제(delete)
    - 컨테이너 상태확인 (state)

**4.5.2 OCI Image Specification**
- 이미지를 구성하는 컴포넌트, 디스크 배치방법, 컴포넌트 미디어 종류 등을 정의
- 매니페스트
  - 이미지를 구성하는 핵심 JSON 파일
  - 컨테이너 이미지 설계도 역할
  - 디스크립터: 이미지를 구성하는 다른 컴포넌트를 가리키는 정보 를 저장
    - 컴포넌트 미디어 종류와 크기, 다이제스트 등이 포함
- 레이어
  - 루트파일 시스템의 구조
  - 보통 tar, gzip으로 압축하는 방식 사용
- 구성파일
  - 컨테이너로 실행할 때 필요한 정보가 기록된 JSON 파일
- 인덱스
  - 선택사항이다
    - 멀티 아키텍처 대응하는 이미지를 만들 때 유용한 JSON 파일
- 인덱스→ 매니페스트→구성파일과 레이어
