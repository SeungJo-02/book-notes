# 1.2 기본적인 컨테이너 기술의 특징

> 🧩 **한 줄 요약** — 컨테이너의 세 가지 강점은 **가벼움 · 이식성 · 생태계**. VM처럼 OS를 통째로 띄우지 않고 **호스트 커널을 공유한 채 네임스페이스로 격리**하기에 가볍고, 표준(OCI) 덕에 어디서든 똑같이 돈다.

## 1. 가벼운 실행 환경 — VM vs 컨테이너

| 구분 | 가상 머신(VM) | 컨테이너 |
|---|---|---|
| 가상화 대상 | **하드웨어**(하이퍼바이저로 가상화) | **OS 커널 공유** 후 프로세스 격리 |
| 자체 OS/커널 | 게스트 OS를 새로 설치 | 없음(호스트 커널 공유) |
| 무게·속도 | 무겁고 느림 | 가볍고 빠름 |

- 컨테이너 = OS 하나를 공유한 채, 그 위 **프로세스들 사이에 가벽만 쳐서** 독립적으로 격리하는 방식.
- 일반 프로세스처럼 **자체 커널이 없다.** 다만 일반 프로세스보다 **훨씬 강하게 환경을 분리**한다.

## 2. 높은 이식성
- 이미지의 **높은 동작 재현성** — 의존 파일을 이미지에 다 넣어두면, 다른 환경에서도 그 이미지로 실행하면 **"내 PC에선 됐는데" 문제**가 사라진다.
- **업계 표준(OCI)** 규격에 따라 컨테이너 조작 방법이 통일돼 있어 도구가 달라도 동일하게 다룰 수 있다.

## 3. 거대한 생태계

| 단체 | 정체 |
|---|---|
| **OCI** (Open Container Initiative) | 컨테이너 **표준 규격**을 정하는 기구 |
| **CNCF** (Cloud Native Computing Foundation) | **쿠버네티스** 등 클라우드 네이티브 기술을 관리하는 단체 |

## 4. 배경 지식 — 격리는 어떻게 이뤄지나

### 4-1. 커널 · 리눅스 · 우분투

| 용어 | 설명 |
|---|---|
| **커널** | OS의 심장. SW와 HW를 잇는 통역사(교통정리·기계 조종·보안). 내 클릭이 기계에 닿으려면 반드시 거침 |
| **리눅스** | 커널의 한 종류. 순수 엔진이라 GUI가 없어 일반 사용자가 그대로 쓰긴 어려움 |
| **우분투** | 리눅스 위에 UI·기본 SW·패키지 관리자(`apt`)를 얹어 바로 쓸 수 있게 만든 OS. 실무의 "리눅스 깔자" ≈ 우분투 설치 |

### 4-2. 하이퍼바이저 vs 네임스페이스 (격리의 두 방식)

| 구분 | 하이퍼바이저 (VM) | 네임스페이스 (컨테이너) |
|---|---|---|
| 무엇을 쪼개나 | **하드웨어**(CPU·메모리·디스크)를 가상 분할 | **실행 중인 프로그램**을 독립된 방으로 분할 |
| 공유 범위 | 물리 기계만 공유, OS는 새로 설치 | 물리 기계 + OS 커널까지 공유 |
| 결과 | 무겁고 느림 | 가볍고 빠름 |

- **네임스페이스** = 컴퓨터 안에 독립된 방을 만들어 주는 리눅스 커널 기능. 대표적 격리:
  - **PID** : 컨테이너는 호스트의 수많은 프로세스 중 **자기 것만** 보임
  - **Network** : 호스트 랜선을 공유하되 **자신만의 IP·포트**를 할당받음
  - **Mount** : 주어진 이미지 파일시스템만 "세상의 전부"로 앎

> 💡 보충 — 네임스페이스가 "무엇을 보이게 할지(격리)"라면, **cgroup**은 "얼마나 쓰게 할지(CPU·메모리 자원 제한)"를 담당한다. 둘이 짝을 이뤄 컨테이너 격리를 완성한다(→ 4.7에서 상세).

- 가벼운 실행환경
  - VM : 하이퍼바이저를 사용한 H/W 가상화 기술
  - 컨테이너 : 호스트의 OS 커널을 기반으로 환경을 격리하는 기술
    - OS는 하나만 공유한 채, 그 위에서 실행되는 가벼운 '프로그램(프로세스)'들 사이에 가벽만 쳐서 독립적으로 격리하는 방식
    - 일반 프로세스와 같이 자체 커널은 없다. 차이점은 컨테이너는 더 강력하게 환경을 분리
- 높은 이식성 : 컨테이너 이미지의 높은 동작 재현성 / 업계 표준 규격에 따른 통일된 조작방법. 이미지에 각종 의존 파일 넣으면 다른 환경에서 실행해도 이식성문제를 피함
- 거대한 생태계 : OCI(컨테이너 표준 규격 기구) / CNCF(쿠버네티스 만든 단체)
- 리눅스 : 커널의 한 종류. 순수 엔진이라 일반 사용자가 그냥 사용은 못함(GUI 없음)
- 우분투 : 리눅스 위에 UI·기본 SW·패키지 관리자(apt)를 얹어 당장 쓸 수 있게 만든 운영체제. 실무 "리눅스 깔자" == 우분투 설치
- 하이퍼바이저 : 큰 컴퓨터를 여러 작은 컴퓨터로 쪼개는 기술. 물리 기계(CPU/메모리/디스크)를 가상으로 쪼갬. OS 새로 설치 + 무겁고 느림
- 네임스페이스 : 컴퓨터 안에 독립된 방을 만드는 리눅스 커널 핵심. 물리 기계+OS까지 공유, 그 위 프로그램을 쪼개 독립된 방을 만듦
  - 하이퍼바이저와 차이 : H/W를 쪼개냐 실행 중인 프로그램을 쪼개냐
  - PID : 컨테이너는 자기 자신만 실행 / Network : 자신만의 독립 IP·포트 / Mount : 주어진 이미지 파일만 세상 전부인줄 앎
- 커널 : OS의 심장 + S/W와 H/W를 잇는 통역사(교통정리·기계 조종·철통 보안)

</details>
